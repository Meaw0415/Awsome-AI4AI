# Recent Agent4AI Additions (2025–2026)

This staging page tracks newly verified papers before deduplication and merge into [`papers.md`](papers.md). The focus is **AI agents for improving AI**: MLE, model training/post-training, data curation, agent-system optimization, algorithm discovery, AI research, and self-improvement.

|:---:|---|---|---|
| 2026 | [Prime Agent: A Self-Improving RLM Harness](https://arxiv.org/abs/2608.23552) | Harness / Long-Horizon | Builds a persistent recursive harness with reusable histories, memories, skills, prompts, and subagents around frozen models. |

## Curation rule

Core papers must directly involve **AI agents improving AI systems or the process used to build them**. Generic planning, memory, tool-use, or harness papers are included only when the mechanism directly improves AI/ML development or a reusable AI-improvement agent.
