# Recent Agent4AI Additions (2025–2026)

This staging page tracks newly verified papers before deduplication and merge into [`papers.md`](papers.md). The focus is **AI agents for improving AI**: MLE, model training/post-training, data curation, agent-system optimization, algorithm discovery, AI research, and self-improvement.

| Year | Paper | Area | Why it matters for Agent4AI |
|:---:|---|---|---|
| 2026 | [Frontis-MA1: Training an AI4AI Model towards Recursive Self-Improvement in Machine Learning Engineering](https://arxiv.org/abs/2607.28568) | Meta-Evolution / MLE | Couples executable environments, execution-grounded SFT/RL, and long-horizon evolutionary search so search experience feeds future improvement. |
| 2026 | [Self-Improving Agents in the Era of Experience: A Survey of Self- to Meta-Evolution](https://openreview.net/forum?id=IUltZSgLMm) | Survey / Self-Improvement | Conceptualizes the progression from self-evolution to meta-evolution and recursive self-improvement. |
| 2026 | [MLEvolve: A Self-Evolving Framework for Automated Machine Learning Algorithm Discovery](https://arxiv.org/abs/2606.06473) | MLE / Evolution | Progressive graph search, retrospective memory, and hierarchical planning for long-horizon ML engineering and algorithm discovery. |
| 2026 | [Meta-Harness: End-to-End Optimization of Model Harnesses](https://arxiv.org/abs/2603.28052) | Harness Optimization | Treats harness source code itself as an outer-loop optimization target using prior source, traces, and scores. |

## Curation rule

Core papers must directly involve **AI agents improving AI systems or the process used to build them**. Generic planning, memory, tool-use, or harness papers are included only when the mechanism directly improves AI/ML development or a reusable AI-improvement agent.
