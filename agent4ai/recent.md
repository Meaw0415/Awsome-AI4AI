# Recent Agent4AI Additions (2025–2026)

This staging page tracks newly verified papers before deduplication and merge into [`papers.md`](papers.md). The focus remains **AI4AI / Agent4AI**: MLE agents, executable learning, research agents, harness optimization, program evolution, post-training, and recursive self-improvement.

## Curation rule

The main Agent4AI table should classify these papers by **optimization object** (solution, policy, memory, harness, research strategy, improver) and **adaptation location** (external search, retrieval/memory, SFT/RL, test-time learning, self-modifying harness). This avoids mixing fundamentally different paradigms under one generic “agent” label.
